## Câu chuyện người dùng

Là người nhận ảnh có token hợp lệ, tôi muốn tải đúng ảnh được cấp quyền bằng UI phù hợp điện thoại.

## Điểm vào và điều hướng

Các màn hình liên quan: [DL-01](../screens/dl-01.md). Điều hướng phải giữ đúng phiên/tenant và theo quyền, không dựa vào việc người dùng biết URL.

## Bố cục sơ bộ

Đây là wireframe nội dung, chưa chốt phong cách thị giác, pixel, font hoặc artwork.

```text
Bộ ảnh của bạn • hạn truy cập
[Ảnh] [Ảnh] [Bản ghép nếu có]
[Tải ảnh này] [Tải tất cả nếu hỗ trợ]
Hướng dẫn lưu ảnh trên điện thoại • Hỗ trợ
```

## Dữ liệu và thành phần UI

| Thành phần | Nguồn nghiệp vụ | Ràng buộc UI |
| --- | --- | --- |
| Danh sách file|Manifest giao file của session|Chỉ các biến thể được sản phẩm cho phép |
| Thumbnail|Bản preview đã tạo|Không yêu cầu tải nguyên ảnh lớn để hiện lưới |
| Link tải|Delivery service kiểm quyền|Thời hạn không vượt quyền truy cập |
| Dung lượng/định dạng|Metadata file|Cho biết trước khi tải gói lớn |

## Hành động

| Hành động | Điều kiện | Kết quả |
| --- | --- | --- |
| Tải file|Token còn hiệu lực và file sẵn sàng|Cấp truy cập đúng file |
| Tải tất cả|Có bundle hoặc cơ chế đã duyệt|Không tạo archive không giới hạn gây quá tải |

## Luồng chính

1. Xem preview trên điện thoại.
2. Chọn ảnh hoặc bộ ảnh.
3. Tải và xem hướng dẫn lưu.
4. Quay lại nếu cần tải thêm trong thời hạn.

## Quy tắc nghiệp vụ đề xuất

* **DL-02-BR-01:** Quyền tải kiểm tra ở server mỗi lần, không chỉ khi mở gallery.
* **DL-02-BR-02:** Loại file giao: original/beauty/frame là D-06.
* **DL-02-BR-03:** Quyền xóa theo yêu cầu cần được xác định D-10; không hiển thị chức năng chưa hỗ trợ.

## Trạng thái và ngoại lệ

Áp dụng thêm [quy tắc UX dùng chung](../ux-principles.md), đặc biệt loading, validation, quyền truy cập, dữ liệu cũ và chống thao tác lặp.

| Tình huống | Hành vi UI/UX |
| --- | --- |
| Một file lỗi|Các file hợp lệ còn tải được; hiển thị file lỗi riêng |
| Token hết hạn khi đang xem|Chặn tải mới với thông báo phù hợp |
| Tải bị ngắt|Cho thử lại còn trong quyền; không tạo phiên chụp mới |

## Tiêu chí nghiệm thu

Các tiêu chí dưới đây là mục tiêu cho thiết kế và triển khai sau khi quyết định liên quan được duyệt.

* **DL-02-AC-01:** Given token chỉ cho session A; When yêu cầu file B; Then server từ chối.
* **DL-02-AC-02:** Given một file chưa sẵn sàng; When mở gallery; Then không gắn nhãn mọi file đã tải được.
* **DL-02-AC-03:** Given truy cập trên màn hình điện thoại; When chọn tải; Then CTA không bị che và tên/định dạng file rõ.

## Phụ thuộc và điểm cần quyết định

* Năng lực hệ thống: [SVC-07](../services/svc-07.md).
* Quyết định còn mở: [D-06](../decisions.md#d-06), [D-10](../decisions.md#d-10).
* Khi quyết định ảnh hưởng đến tiền, license, retention hoặc side effect chưa được duyệt, chỉ thiết kế trạng thái; chưa coi story đủ điều kiện triển khai thương mại.

## Bàn giao UI/UX

Bản thiết kế cần thể hiện bố cục, nội dung CTA, trạng thái tương ứng ở trên, đường đi tới màn hình liên quan, và đánh dấu rõ mọi giả định. BA này không tự cấp quyền truy cập ảnh, chốt giá hoặc xác định chính sách pháp lý.
